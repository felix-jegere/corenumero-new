# CoreNumero

Modern Number Intelligence Dashboard built with React + Vite + Tailwind CSS.

## Features
- Live number generator
- Interactive counter
- Real-time statistics
- Beautiful glassmorphic UI

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- Lucide Icons

## Getting Started

```bash
npm install
npm run dev
```

Deployed easily on Vercel.
